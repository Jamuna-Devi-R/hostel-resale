# 🏠 Hostel Resale Management System

A simple and practical web platform built for hostel students to buy and sell their used items — books, electronics, furniture, and more — without any hassle.

 Why This Project?

Hostel students often struggle to sell or find affordable second-hand items. This platform bridges that gap by connecting buyers and sellers within the same hostel community.

Features

-  User Registration & Secure Login
-  List items for sale with images and descriptions
-  Search and filter products by category
-  Express interest in buying an item
-  Seller dashboard to manage listings
-  Mark items as sold or delete them
-  View interested buyers and confirm sales

Tech Stack

- **Frontend:** HTML, CSS
- **Backend:** PHP
- **Database:** MySQL
- **Server:** Apache (XAMPP)
